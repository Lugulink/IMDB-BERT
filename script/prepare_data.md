# Dataset preparation

This project uses IMDB movie review CSV files.

Due to dataset size , the CSV files are not included
in this repository.

Expected CSV format:
- username
- rating
- helpful
- total
- date
- title
- review

Each movie should have its own CSV file, placed in:

data/commentaire/

Example:
data/commentaire/
├── Avatar 2009.csv
├── Interstellar 2014.csv
├── Casino Royale 2006.csv
